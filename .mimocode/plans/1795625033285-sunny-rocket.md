# Доделать рендер относительно камеры (минимум)

## Диагноз: что забыто

Заготовки уже на месте (`Camera`, `CameraUniform`, `RawGpuCamera`, `RawDrawPass::set_camera`, `RawGlobalBindGroupLayout`), но цепочка оборвана — камера ни на что не влияет:

1. **Layout группы 0 не подключён** — `dum-hell/src/pipeline/raw_render_pipeline_layout.rs:19`: на слоте 0 стоит `None`, хотя параметр `global` передаётся в функцию и игнорируется.
2. **Камеры нет в шейдере** — `dum-hell/src/shader/vertex.wgsl` считает `object.model * pos` без `view_projection`.
3. **Нет фабрики создания и обновления** — `RawGpuCamera::new` есть, но из sandbox его не вызвать (нет доступа к `wgpu::Device` и global layout); `update` отсутствует.
4. **Sandbox не использует камеру** — камера не создаётся, `pass.set_camera` не вызывается.

View-матрицу `Camera` не хранит — её считает вызывающая сторона через `Camera::view_projection_matrix(view)` (`camera.rs:9`, порядок `projection * view` уже верный). В plam есть `Mat4::unchecked_look_at_rh(eye, center, up)`.

Вне scope: обработка `SurfaceResized`/aspect при ресайзе, фикс `RawGpuModel::update`, depth buffer.

## Шаги

### 1. Подключить global layout в пайплайн
`dum-hell/src/pipeline/raw_render_pipeline_layout.rs` — заменить `None` на `Some(global.raw())` в слоте 0:
```rust
bind_group_layouts: &[Some(global.raw()), Some(material.raw()), Some(object.raw())],
```

### 2. Добавить камеру в вершинный шейдер
`dum-hell/src/shader/vertex.wgsl` — uniform группы 0 (соответствует `set_camera` → bind group 0 в `raw_draw_pass.rs:17`) и умножение:
```wgsl
struct CameraUniform {
    view_projection: mat4x4<f32>,
};

@group(0) @binding(0)
var<uniform> camera: CameraUniform;
```
в `vs_main`:
```wgsl
output.position =
    camera.view_projection * object.model * vec4<f32>(input.position, 1.0);
```

### 3. Создание и обновление
По образцу `create_gpu_model` (`raw_graphics_device.rs:40`, `raw_orchestrator.rs:176`):

- `dum-hell/src/gpu/raw_graphics_device.rs`:
  ```rust
  pub fn create_gpu_camera(
      &self,
      view_projection: plam::Mat4,
      global_bind_group_layout: &wgpu::BindGroupLayout,
  ) -> RawGpuCamera {
      RawGpuCamera::new(&self.device, global_bind_group_layout, view_projection)
  }
  ```
- `dum-hell/src/gpu/raw_orchestrator.rs`:
  ```rust
  pub fn create_gpu_camera(&self, view_projection: plam::Mat4) -> RawGpuCamera {
      self.device
          .create_gpu_camera(view_projection, &self.pipeline.global_layout())
  }

  pub fn update_gpu_camera(&self, camera: &RawGpuCamera, view_projection: plam::Mat4) {
      camera.update(&self.device, view_projection);
  }
  ```
- `dum-hell/src/camera/raw_gpu_camera.rs` (сигнатура `&self` + `&RawGraphicsDevice`, не по значению):
  ```rust
  pub fn update(&self, device: &RawGraphicsDevice, view_projection: plam::Mat4) {
      device.write_buffer(&self.buffer, &CameraUniform::from_mat4(view_projection));
  }
  ```
  Буфер уже имеет `COPY_DST` (`raw_gpu_camera.rs:17`). Вызывать `update` до `end_frame` (это submit), иначе запись попадёт в следующий кадр.

### 4. Сборка в sandbox
`dum-sandbox/src/main.rs`:
- `DumApp` — добавить поля `camera: Option<dum::Camera>` и `gpu_camera: Option<dum::RawGpuCamera>`.
- `start` — создать `dum::Camera::default()`, один раз выставить aspect: `camera.set_aspect_from_surface(window.size())`, создать `gpu_camera = orchest.create_gpu_camera(vp)` и сохранить оба в `DumApp`.
- `event` / `RedrawRequested` — вычислить view, обновить uniform, затем в колбэке `render_pass` **до** `pass.draw` вызвать `pass.set_camera`:
  ```rust
  let view = plam::Mat4::unchecked_look_at_rh(
      plam::Vec3::unchecked_new(0.0, 0.0, 3.0), // eye
      plam::Vec3::ZERO,                          // center
      plam::Vec3::unchecked_new(0.0, 1.0, 0.0),  // up (в plam нет Vec3::Y)
  );
  let vp = camera.view_projection_matrix(view);
  orchest.update_gpu_camera(gpu_camera, vp);
  // ...
  frame.render_pass(desc, |pass| {
      pass.set_camera(gpu_camera);
      // существующие mesh / model / material / draw
  });
  ```
  Порядок внутри pass важен: bind group 0 должен быть установлен до первого draw (`draw` ставит только группы 1–2).

## Проверка
1. `cargo run -p dum-sandbox` — красный треугольник виден в перспективе (камера на z=3 смотрит в центр).
2. Поменять eye на `(0, 0, 5)` — треугольник мельче; `(0, 0, 1)` — крупнее (clip = VP·M·pos работает).
3. Сместить `Model::set_position` — треугольник смещается в кадре (model-часть не сломана).
